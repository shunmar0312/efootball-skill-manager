\# eFootball Skill Manager



eFootball™の選手・スキル管理を目的として制作した非公式の個人用Webツールです。



\## 主な機能



\- 選手の登録・編集

\- 登録ポジションの管理

\- 所持スキルの管理

\- 追加したいスキルの管理

\- 追加スキルの取得状況管理

\- ポジション別おすすめスキルの表示

\- 特別強化用選手の管理

\- 特別強化用選手と追加希望スキルのマッチング
